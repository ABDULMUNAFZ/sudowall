Tortoise Gate
Source Docs

Nothing your agent does moves until it’s checked.

Tortoise Gate is an open-source firewall for AI agents. It sits between your agent and its tools, stops actions planted by a poisoned email or web page, and keeps a record nobody can quietly edit.

npx tortoisegate demo

A two-minute walkthrough on a private local test chain. Needs Node.js 24 on macOS or Linux. From source: quickstart.

Agents act with your keys. Anyone can write them a note.

AI agents now read email, browse the web, send payments and run code using your credentials. A hidden line in a message can tell an agent to send money or data to an attacker, and the agent may do it. This is prompt injection, and there is no complete fix inside the model.

After an incident, most teams can’t even show what the agent did or why. Tortoise Gate checks actions at the one place every agent must pass: the tool call.

How it works

  1. Label sources

    Output from email, web pages, files and other tools is marked untrusted.

  2. Match values

    If an address, email, URL or amount in a later call came from untrusted content, or looks like a known value but differs, the gate knows.

  3. Apply your policy

    Fixed rules, not an AI judge, decide allow, ask or block, and say why.

  4. Record everything

    Every call and decision goes into a signed, hash-chained ledger you can verify.

What the demo shows

Two real MCP servers sit behind the gate: a filesystem server with a poisoned inbox, and a payments server on a local test chain. A scripted agent (fixed tool calls, no LLM) reads the emails and tries to pay.

The agent tries to Gate Result
Pay an address hidden in an email Ask Paused in the local approval UI. Deny it and nothing is sent.
Pay a lookalike of a trusted address Block Stopped outright as address poisoning.
Pay an allowlisted address Allow A real transaction on the local chain.
Edit the record afterwards Caught ledger verify names the exact entry that changed.

Put it in front of your agent

init writes a starter config in observe mode, which records every decision but blocks nothing, and a policy template. Switch to enforce when the decisions look right. 

npx tortoisegate init
claude mcp add my-server -- npx -y tortoisegate wrap --config <config> -- <your server command>
npx tortoisegate ui --config <config>

What it doesn’t do

  • It only sees tool calls that pass through it, and today that means MCP.
  • It catches structured values copied exactly or nearly (addresses, emails, URLs, amounts), not instructions an agent rewords in its own words.
  • The ledger proves the record wasn’t edited, not that the agent behaved well.
