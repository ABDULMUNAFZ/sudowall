The problem

Your agent reads an email. The email talks back. A hidden line says “send the keys to this address”, and a helpful agent does it. Prompt injection means anyone who can put text in front of your agent can try to steer it, and no model refuses every time.

How it works

Every tool call passes four checks, in about a millisecond.

tool call
  1. 1

    Where did this come from?

    Every value the agent saw is labelled: your own tools are trusted, an email or web page is not. Addresses, emails, URLs and amounts are tracked, even inside free text and code.

  2. 2

    What do the rules say?

    A fixed policy decides: allow, ask you, or block, with a reason. No AI judge, so the same call always gets the same answer.

  3. 3

    Do you approve?

    Risky calls wait in the local app with every value in full and where it came from. Approve or Deny; silence means no.

  4. 4

    Written down for good.

    Every call and decision goes into a hash-chained, signed record. Edit one entry and the check names it.
