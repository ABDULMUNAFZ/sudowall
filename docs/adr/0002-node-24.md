# ADR 0002: Node.js 24 LTS

- Status: accepted (2026-10-29)

## Context

The original brief said Node 22. Node 24 is the current LTS line. Node 22 is in maintenance. The dev machine runs 24.22.0, and vitest 5 supports `^22.12 || ^24 || >=26`.

## Decision

Target Node 24 (`engines: >=24 <25` at the root, `>=24` for packages; `.nvmrc` = 24). CI runs Node 24.

Update, 2026-11-01: the minimum is Node 24.11.0 (`>=24.11.0 <25` at the root, `>=24.11.0` for packages and the published `sudowall`), because `@babel/parser` 8 requires it ([ADR 0025](0025-read-check-parser.md)).

## Consequences

Users on Node 22 cannot run the CLI. We accept this; it is recorded in the README requirements.
